# Rich block lane

Sources reviewed: `fluxer_app/src/features/theme/styles/Markup.module.css`, `BlockElements.tsx`, `CodeElements.tsx`, and `ArboriumHighlighting.ts`. The checked-in Rust Markdown parser supplies structure; Arborium 2.18.2 supplies the same syntax captures used by the web client.

Implemented: heading font scales and margins with variable-height rows; nested ordered and unordered markers with hanging continuation indentation; type-colored alert rules; real table cell ranges, wrapping, alignment, grid, horizontal wheel/Shift-wheel scrolling and draggable overflow thumb. The row geometry drives drawing, selection, hit testing, inline emoji, and activation anchors. Table selection copies rendered cells separated by tabs and rows by newlines, excluding concealed spoiler spans. Code blocks have a language label, Copy action with two-second acknowledgement for exact parser content, and Arborium captures colored with its GitHub Dark theme. Copy Message still uses original Markdown. Highlighting runs off the UI thread, with bounded input, a FIFO queue of lightweight cancellable tickets, a 12-second wait deadline, stale generation rejection, and a bounded cache.

Limits: The browser worker can be terminated after a timeout; Rust parser tasks cannot be forcibly stopped. Queue entries expire after 12 seconds; unsupported or oversized blocks remain plain. The active parser cannot be terminated early. Alert icons, localized alert labels and vertical card padding remain incomplete. Heading level six uppercase transform is not implemented. Keyboard activation of the code Copy control and pointer overflow-thumb behavior require GUI validation, as do selection across wrapped cells, clipped activation anchors, horizontal scrolling, and interaction among emoji/spoilers/code and tables. This lane did not launch an app or capture screenshots.

Automated coverage includes Unicode, spoilers, emoji, clipping, compact authors, nested list markers and continuation ranges, repeated Copy feedback, outside-release drag state, table byte ranges/alignment/copy and cell-first hit testing through empty/padded/scrolled cells, exact code copy, and real Arborium Rust capture/theme byte offsets. GUI inspection remains required.
