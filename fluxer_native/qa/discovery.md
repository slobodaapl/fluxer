# Explore communities

On an authenticated multi-community instance with discovery enabled, open Explore from the home sidebar. Search for a name, choose a category, enter a language code, and use Load more when available. Results and counts come from that selected instance. Empty results and request failures are shown in the pane. Switching accounts or instances clears the directory and ignores outstanding responses.

Single-community and discovery-disabled instances do not show Explore. The server remains authoritative for discovery eligibility. Select Join on a result and confirm it to request membership. Cancel sends no join request. A pending request cannot be submitted twice; after a timeout, check the sidebar before retrying. Visitor sessions, channel previews and listing management are not implemented by this slice.
