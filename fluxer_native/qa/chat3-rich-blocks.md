# Rich block lane

Sources reviewed: `fluxer_app/src/features/theme/styles/Markup.module.css`, `BlockElements.tsx`, `CodeElements.tsx`, and `ArboriumHighlighting.ts`. The checked-in Rust Markdown parser supplies structure; Arborium 2.18.2 supplies the same syntax captures used by the web client.

Implemented: heading font scales and margins with variable-height rows; nested ordered and unordered markers; type-colored alert rules; real table cell ranges, wrapping, alignment, grid, horizontal wheel/Shift-wheel scrolling and draggable overflow thumb. The row geometry drives drawing, selection, hit testing, inline emoji, and activation anchors. Table selection copies rendered cells separated by tabs and rows by newlines, excluding concealed spoiler spans. Code blocks have a language label, Copy action for exact parser content, and Arborium captures colored with its GitHub Dark theme. Copy Message still uses original Markdown. Highlighting runs off the UI thread, with bounded input and in-flight tasks and stale generation rejection.

Limits: The browser worker can be terminated after a timeout; Rust parser tasks cannot be forcibly stopped. When the eight-task limit is saturated, excess blocks remain plain until their document is refreshed. Unsupported or oversized languages/content remain plain. Alert icons, localized alert labels and vertical card padding remain incomplete. Heading level six uppercase transform is not implemented. Keyboard access to the code Copy control and overflow thumb requires GUI validation, as do selection across wrapped cells, clipped activation anchors, horizontal scrolling, and interaction among emoji/spoilers/code and tables. This lane did not launch an app or capture screenshots.

Automated coverage includes Unicode, spoilers, emoji, clipping, compact authors, nested list markers, table byte ranges/alignment/copy, exact code copy, and real Arborium Rust capture/theme byte offsets. GUI inspection remains required.
