Native copies of the existing client's Fluxer Sans and Fluxer Mono fonts. WOFF2 files from packages/fonts/files were decompressed to SFNT/TTF with fontTools (recalcTimestamp=False); glyphs, names, weights, and styles are unchanged. Original font provenance/build rules are in tools/fonts/fonts.lock.json and tools/fonts/build_fonts.py. See NOTICE.md and LICENSE-IBM-PLEX.txt (SIL OFL 1.1). Source and converted hashes are recorded in provenance.json. No runtime download or fontTools dependency is required. Locale/script fallback remains provided by the system text engine.
